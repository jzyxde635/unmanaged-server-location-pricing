## 免备案服务器租用，免掉的到底是什么

免的是 ICP 备案，不是域名实名，也不是所有监管。

备案的触发条件很明确：中国大陆节点 + 域名解析过去对外提供网站服务。换成香港或海外节点，这条义务就不成立。它跟你用 80 端口还是 8080、8443 无关——备案不区分端口，只要解析指向大陆 IP 就得备。

省下来的主要是时间。走一遍完整流程，接入商初审一般 1–2 个工作日，提交管局后各省审核不超过 20 个工作日，中途资料被打回重来是常事。免备案服务器付款后几分钟就能拿到 IP，这是它最实在的价值。

代价有三条，提前想清楚：

1. **香港带宽小、单价高。** 传统香港机房 1M 起步，2M、3M 就明显涨价，跟美国机房 1G 起步完全不是一个量级。
2. **美国带宽大、延迟高。** 内容限制少、流量给得爽，但大陆访问绕半个地球，实时交互类业务基本没戏。
3. **云厂商的香港“入门型”套餐不保障跨境公网质量。** 同样的价格，锐驰型或通用型才是面向大陆用户设计的。

还有一条容易被忽略：不需要 ICP 备案 ≠ 不需要域名实名。域名该认证还是要认证，没实名连解析都开不了。
